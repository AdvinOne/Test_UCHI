# Проверка доступа и контрольной

Основная страница: https://advinone.github.io/Test_UCHI/course.html?subject=math&work=2.
Настройки: https://advinone.github.io/Test_UCHI/demo.html.

1. В настройках сбросить состояние на 20 бусин, подтвердив сброс. На курсе должно быть 20 бусин, 0 яиц. Переключение предметов/работ ничего не списывает. Остальные варианты остаются недоступными.
2. Открыть вариант 1 математики, КР №2. Должно остаться 5 бусин. Ввести часть ответов и обновить: ответы сохранены, баланс 5. Вернуться к курсу и продолжить карточкой: та же попытка, баланс 5.
3. На курсе выбрать «Начать новую попытку». Показан детский экран с причиной (5 из 15), без цены и требования купить. Отказ/возврат сохраняет ответы. Кнопка «Продолжить начатую попытку бесплатно» возвращает к тем же ответам.
4. «Взрослый рядом» открывает фиолетовый paywall: 1 500 ₽/год, 1 курс, три бенефита, ограничение демо. Оттуда перейти к подтверждению. Неверный пример показывает ошибку без перехода. Верный ответ и галочка открывают тарифы.
5. На тарифах выбран только годовой доступ к контрольным. Пакеты и другие сроки недоступны. Refresh сохраняет доступ к этому шагу. «Назад» в браузере возвращает на предыдущий шаг. Без подтверждения прямые `access.html#plans` и `access.html#checkout` отправляют к подтверждению.
6. Демо-оформление не запрашивает карту. Кнопка неуспешной покупки показывает ошибку: баланс, доступ, яйца прежние. После галочки «Открыть демо-доступ» показывает успех. Двойной клик/refresh не создаёт повторную покупку, ничего не списывает.
7. «Вернуться к контрольной» начинает именно запрошенную новую попытку: чистые ответы, 5 бусин, 0 яиц, демо-доступ открыт. Текущая страница после refresh не начинает ещё одну попытку. Переход назад к старой заменённой попытке не списывает бусины: показывает понятное сообщение с возвратом.
8. Пройти все 11 экранов. В первом ввести `0, 7, 64, 47`, нажать «Готово»: первое поле красное, остальные зелёные, поля блокируются. Refresh сохраняет проверку; «Далее» переводит на второй экран. Аналогично проверить dropdown и выбор картинки.
9. Ответы для полного прохождения: №1 `16,7,64,47`; №2 `9,48,100`; №3 `16,7,64,47`; №4 `33,33,70,85,85,21`; №5 `3,4,1,30`; №6 `=,<,>`; №7 «Найти время полёта», затем «Найти экономию времени»; №8 `24,6,4,24,4,20,20`; №9 прямоугольник 3; №10 `21,20`; №11 `36`. «Готово» проверяет, «Далее» продвигает. Неверные ответы разрешают завершение.
10. После последнего «Далее» показаны результат и 2 яйца, баланс остаётся 5. Refresh, просмотр результата с курса, возвраты назад не начисляют ещё 2 яйца. «Пройти ещё раз» при демо-доступе начинает новую попытку бесплатно; яйца остаются 2 до нового завершения.
11. Сбросить на 15: новый старт даёт 0, продолжение бесплатно, новый старт блокируется. Сбросить на 14, 5 и 0: сразу детский экран, баланс не меняется. Сбросить на 20: начать в двух вкладках одновременно — один идентификатор попытки и только одно списание. Изменить ответы в двух вкладках: устаревшее сохранение отклоняется с просьбой обновить.
12. Сбросить состояние при открытой другой вкладке с работой. Старая вкладка не может восстановить старый баланс/попытку сохранением. Настройки сбрасывают только обычный курс: данные «Башни» не затронуты. При недоступном хранилище запуск сообщает ошибку, не начинает бесплатную несохраняемую работу.
13. Повторить ключевые шаги на ширинах 360, 390, 640, 1280: нет горизонтальной прокрутки, кнопки и поля доступны с клавиатуры, текст не обрезан. У кнопок есть видимый фокус, ошибки объявляются через `role=alert`.

Состояние хранится на домене и в браузере. У другого браузера, приватного окна или локального сервера собственный баланс. Сброс не влияет на реальные продукты Учи.ру.
