# Эксперимент: башня → город

Стабильный снимок всей актуальной контрольной (11 заданий и явная проверка по «Готово»): `baseline/control-works-2026-10-16`, коммит `45944ffdfce8dbbc9378d9885af758329c1f2b61`.

Эксперимент: `experiment/tower-builder`. Основной `main` и существующие страницы контрольной не меняются.

## Открыть одновременно

```sh
python3 -m http.server 4174 --directory dist
```

- Проба механики: http://localhost:4174/experiments/tower/
- Обычная контрольная: http://localhost:4174/course.html?subject=math&work=2

Обе страницы можно открыть одновременно. Результаты обычной контрольной используют старый ключ `uchi-math-inputs-v1`. Эксперимент читает и пишет только `uchi-experiment-tower-v1`.

## Сценарий

Используется первое исходное задание, четыре примера. Чтобы увидеть полноценную башню за одно задание, **в демо один ответ даёт один этаж**. Дальше адаптер может принимать один итоговый результат на задание — без переделки заданий или игры.

До «Готово» ответы свободно редактируются; blur не проверяет их. После подтверждения ввод блокируется, четыре этажа последовательно приземляются: верные ровно, ошибочные с наклоном. Нет таймера и обрушения. Башня автоматически сохраняется в «Мой город». Перезагрузка не дублирует постройку. Кнопка «Попробовать заново» очищает только текущую попытку и сохраняет город.

Верные ответы для проверки: **16, 7, 64, 47**. Например **16, 8, 64, 48** дают два наклонённых этажа.

`tower-engine.js` не зависит от предмета, DOM и вида задания: принимает массив окончательных результатов `boolean[]`. `tower.js` связывает его с первым заданием через существующие `expected` и `evaluate`. Ключи и вычисление оценки обычной контрольной не используются.

На узком экране сцена располагается под заданием. Учтены клавиатура, подписи полей, `aria-live`, `prefers-reduced-motion` и недоступный localStorage.

GitHub Pages настроен на `main`: push экспериментальной ветки сам по себе не публикует её поверх обычной контрольной. Для тестирования предназначен отдельный локальный адрес. Не запускайте workflow Pages вручную для экспериментальной ветки: он заменит основной опубликованный сайт.
