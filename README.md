# Контрольные работы — прототип

Страница курса контрольных работ и 11 последовательных экранов: инпуты, дропдауны и выбор картинки, математика 3 класса.

## Запуск

Без сборки и внешних зависимостей:

```sh
python3 -m http.server 4173 --directory dist
```

Страница курса: http://localhost:4173/course.html?subject=math&work=2.
Прямой запуск заданий: http://localhost:4173/index.html.

## Правила

- Полная последовательность следует порядку слева направо в секции «Математика 3 кл» на странице «2026 макеты заданий». Подписи 1–8 относятся к исходным инпутам; в полной последовательности 11 экранов.
- № 1 и № 3 повторяются намеренно, как в источнике.
- Ответы можно редактировать до проверки. Когда все поля заполнены, активируется «Готово». Проверка происходит только по нажатию этой кнопки.
- После проверки все поля блокируются, верные ответы зелёные, неверные красные. Кнопка меняется на «Далее» и только по нажатию открывает следующее задание.
- Черновики, проверенные ответы, позиция, баланс и яйца сохраняются в IndexedDB этого браузера (подробности ниже).
- После 11-го экрана показаны оценка, количество верных экранов и отдельных ответов (37). Прежняя шкала сохранена в долях: 100% → 5, от 75% → 4, от 50% → 3, иначе 2; для 11 экранов это 11 / 9–10 / 6–8 / 0–5.
- Добавлены: сравнение величин (экран 6), план решения задачи о самолёте (экран 7), выбор прямоугольника (экран 9). Исходные инпуты самолёта и геометрии идут после соответствующих шагов.
- UI взят из экранов под Ellipse 1729: цвета, прогресс, крупные поля 96×80, кнопка. Шрифт Factor A не поставляется с макетом через MCP, поэтому предусмотрен системный Arial fallback.

## Страница курса

- Четыре предмета и пять контрольных работ переключаются без перезагрузки; выбор хранится в URL.
- Доступен только вариант 1 (лёгкий) по математике в КР №2 (октябрь). Остальные варианты не интерактивны.
- Прогресс и оценка берутся из той же попытки IndexedDB, что и задания. До завершения показывается «В процессе», после — оценка.
- Результат сохраняется в этом браузере; другая сессия или устройство имеют собственный прогресс.
- `dist/course.html`, `course.css`, `course.js` — страница курса; `math-data.js` — общие условия, проверка сохранения и расчёт оценки.
- `dist/assets/course-shell.png` — исходный растровый ресурс Figma для фрагментов карточек и шапки; `math-icon.svg` — исходная иконка.
- Макет: https://www.figma.com/design/3lUBn6Ji7ycNu6CGtL7pSh?node-id=3763-14108

## Дополненные механики

- Дропдауны используют светло-синий фон, скругление 12px и размеры из макетов dropdown-M / dropdown-S. Проверка и блокировка происходят по «Готово» после выбора всех значений; ошибки красные, верные выборы зелёные.
- В макете план решения представлен закрытыми списками без текста вариантов. Пункты восстановлены по условию: сначала время полёта, затем экономия времени; оба пункта доступны в каждом списке.
- Выбор картинки использует крупные карточки 390×390 в сетке два на два с обводкой и тенью из макета. Внутри — фрагменты оригинального загруженного PNG с прямоугольниками, без перерисовки; правильный вариант — 3. На узком телефоне (до 480px) карточки идут по одной и занимают всю ширину.
- Нажатие на картинку сохраняет редактируемый выбор с фиолетовой рамкой. «Готово» проверяет и блокирует выбор, «Далее» открывает следующий экран.
- Старое состояние из 8 инпутов мигрирует в версию 2 под тем же ключом: ответы сохраняются на своих экранах, а текущим становится первый недостающий шаг. Оценка за полную работу появляется после всех 11 экранов.
## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует содержимое `dist` после изменений в ветке `main`. В Settings → Pages нужно выбрать источник GitHub Actions.

Страница курса доступна по адресу `<адрес сайта>/course.html?subject=math&work=2`, задания — `<адрес сайта>/index.html`. Все ссылки и ресурсы относительные и работают в подкаталоге репозитория.

Прогресс хранится локально в браузере и не переносится с домена ChatGPT Sites на GitHub Pages.

## Бусины, попытки и демо-покупка

- Новый ученик получает 20 бусин. Просмотр курса бесплатный. Открытие готового варианта впервые начинает попытку и списывает 15 бусин: остаётся 5. Баланс в шапке теперь настоящий текст, а не растровый фрагмент.
- Возврат в начатую попытку, обновление, повторные клики и просмотр результата не стоят бусин. Новый старт — через «Пройти ещё раз» после результата или «Начать новую попытку» на курсе. Старая попытка заменяется только после успешного старта новой; при недостатке бусин ответы сохраняются.
- Баланс, текущая попытка, её ответы, признак награды и демо-доступ хранятся одной записью `student` в базе `uchi-control-demo-v1`, хранилище `account`. Старт и списание — одна сериализуемая readwrite-транзакция IndexedDB, включая разные вкладки. Токен старта предотвращает повторное списание при refresh/back; старые запросы и устаревшие сохранения отклоняются.
- Завершение всех 11 экранов даёт **2 яйца один раз за попытку**, независимо от оценки. Яйца не оплачивают старт и не уменьшают стоимость в бусинах. Прогресс и начисление награды сохраняются одной транзакцией.
- Старый `uchi-math-inputs-v1` читается только для первоначальной миграции. Уже начатая старая работа принимается как оплаченная: 5 бусин; завершённая получает 2 яйца. Это прозрачное допущение для старых сохранений, где не было данных о платежах. Эксперимент «Башня» остаётся изолированным.
- Если хранилище недоступно или запись повреждена, запуск закрывается с объяснением; молчаливого сброса и бесплатных повторов нет. Настройки демо позволяют восстановить повреждённую запись.
- Недостаток бусин → детский экран → родительский фиолетовый paywall → арифметическое подтверждение взрослого → тарифы → демо-оформление → результат → возврат к запрошенному старту. Закрытие покупки не списывает бусины и не стирает предыдущие ответы.
- Из Figma использованы paywall `4186:30896`, выбранный курс `3911:18100`, корзина `3911:22044`, оформление `3911:22722`. Оригинальные SVG сохранены локально в `dist/assets/paywall/`. Сохранены фиолетовый фон, тёмная панель, три бенефита и оранжевая кнопка; разделены детский и родительский тексты.
- Единственное рабочее предложение — **«Контрольные работы», 1 500 ₽ за год** из paywall-макета. 125 ₽/мес — только арифметический пересчёт, не рассрочка. Пакеты «Только школа» и «Всё на Учи.ру» показаны как недоступные варианты из макета без выдуманных условий. Месяц и полгода не подключены. Скидки, таймеры и социальное доказательство из черновых макетов не используются.
- Покупка полностью демонстрационная: реквизиты не запрашиваются, платёжных запросов и реальных списаний нет. Она открывает локальный демо-доступ на календарный год, новые попытки без бусин, не меняет баланс и яйца. Реализованы неуспешный результат, повтор, успешный результат и защита от дублей.
- В демо доступна только готовая лёгкая работа по математике 3 класса, КР №2. Подтверждение взрослого — демонстрационная передача устройства, не проверка возраста/личности. Оно действует 15 минут в текущей вкладке; прямой переход к тарифам/оформлению без него возвращает к подтверждению.
- Это локальный прототип, не защищённый биллинг: для реальной оплаты необходимы серверная авторизация, серверный баланс и проверка платежа. Изменение данных через инструменты разработчика возможно.

Сброс: `demo.html` → выбрать 20 / 15 / 14 / 5 / 0 → «Сбросить демо-состояние» → подтвердить. Удаляются только текущие ответы, локальные бусины, яйца, демо-доступ и старое сохранение обычного курса. Данные «Башни» и другие данные сайта не затрагиваются.

Проверки: `node --test tests/*.test.cjs`. Браузерный сценарий: `node tests/access-flow.browser.cjs` при установленном `playwright` и Google Chrome (можно указать `CHROME_PATH`). `TEST_BASE_URL` позволяет пройти тот же сценарий на опубликованном сайте; используется изолированный браузерный профиль. Подробный ручной чек-лист — `docs/TESTING-ACCESS.md`.
