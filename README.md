# Контрольные работы — прототип

Этап 1: восемь последовательных заданий с числовыми инпутами, математика 3 класса.

## Запуск

Без сборки и внешних зависимостей:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173.

## Правила

- Номера 1–8 соответствуют подписям в секции «Математика 3 кл» на странице «2026 макеты заданий».
- № 1 и № 3 повторяются намеренно, как в источнике.
- Ответы можно редактировать до проверки. Проверка происходит при выходе из поля, если все поля заполнены числами.
- После проверки все поля блокируются, неверные ответы красные, «Продолжить» открывает следующее задание.
- Черновики, проверенные ответы и позиция сохраняются в localStorage этого браузера.
- После восьмого задания показаны количества заданий без ошибок, заданий с ошибками и верных отдельных ответов. Оценка по шкале пока не рассчитывается.
- К шагам № 6 и № 7 добавлены исходные условия с предыдущих скриншотов, чтобы их можно было решить отдельно от механик dropdown и выбора картинок.
- UI взят из экранов под Ellipse 1729: цвета, прогресс, крупные поля 96×80, кнопка. Шрифт Factor A не поставляется с макетом через MCP, поэтому предусмотрен системный Arial fallback.

Источник: https://www.figma.com/design/3lUBn6Ji7ycNu6CGtL7pSh?node-id=3775-15673

## Файлы

- `dist/index.html` — оболочка.
- `dist/styles.css` — UI и мобильная адаптация.
- `dist/app.js` — условия, ключи ответов, состояние и проверка.
- `.openai/hosting.json` — конфигурация опубликованного прототипа.
